# DMS Invoice Report Converter and Remittance Status Report

A single-page tool that runs entirely in the browser. Upload the raw DMS file (.xlsx or .csv); nothing is sent to any server.

- **Invoice Report Converter:** dealer-wise report by invoice month, with month and dealer filters and an Excel download.
- **Remittance Status Report (Part 1):** the "Invoice status" summary table with an Excel download.

## Run locally
Open `index.html` in a browser (internet is needed once to load the Excel library from cdnjs).

## Host on GitHub Pages
1. Create a repository and upload `index.html` (and this README).
2. Settings > Pages > Source: "Deploy from a branch" > branch `main`, folder `/ (root)` > Save.
3. Open the link GitHub shows after a minute or two.
